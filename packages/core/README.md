# @vueform/core

Headless, schema-driven form framework core for Vue 3 — elements, validation, conditions and form state.

> **Alpha**: Vueform 2 is in early alpha. APIs may change between releases without notice.

## Installation

```sh
npm install @vueform/core@alpha
```

Most applications use `@vueform/core` through a UI layer such as [`@vueform/ui`](https://github.com/vueform/next/tree/main/packages/ui) or an adapter like [`@vueform/primevue`](https://github.com/vueform/next/tree/main/packages/primevue).

## Documentation

See the [Vueform repository](https://github.com/vueform/next) for documentation and examples.
