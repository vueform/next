# `useSecurity`

<!-- #region description -->
Returns the security module (sanitizer and `encrypt` / `decrypt` ciphers), or its inert surface (passthroughs) when the `security` module is not registered.

Setup-only: resolves the calling component's instance. Outside a component use `getSecurityModule(vueform)`.
