# `defineSchema`

<!-- #region description -->
Identity helper that validates and `const`-narrows a form schema so it can drive type-level features. Each entry is validated against its registered element's props, and an optional Standard Schema (Zod, Valibot, ArkType, …) can be passed for form-level validation.
